👤 Usuários

Por limitação do Firebase, um app da web só pode criar contas novas e revogar o acesso de alguém (a pessoa não consegue mais entrar). Não é possível excluir a conta de outra pessoa de verdade por aqui — para isso, use o Firebase Console → Authentication → Users.

🚚 Histórico de cargas

Cada carga finalizada aparece aqui. Você pode excluir uma por uma — o que for excluído fica guardado na lixeira por segurança.

📍 Destinos — buscar e padronizar

Aqui aparecem os destinos exatamente como foram digitados. Se "sp" e "SP" aparecem separados, use "Aplicar" para renomear todos os registros de um destino de uma vez.
